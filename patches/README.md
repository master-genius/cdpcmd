# node_modules 本地补丁

**当前没有生效中的补丁。**

本目录只在"依赖里发现问题、但上游还没发版"的过渡期存在补丁文件；
改动一旦进入上游发布版本，补丁就删掉——留着一份已经无法应用（或会重复应用）
的补丁，比没有更危险。

## 为什么这个目录有存在的必要

本仓库把 `node_modules` 纳入了 git，所以对依赖的本地改动是持久的——
但 `npm install` / `npm ci` 会用 registry 的原始包覆盖它们，**且不会有任何提示**。
过渡期一旦忘了这件事，改动就在某次安装后无声无息地消失了。

因此约定：

- **代码类改动必须同时留一份补丁**，作为"这里被本地改过"的凭据与搬去上游的载体；
- **纯文档改动不出补丁**（依赖包里的 README 等）：没有运行时影响，
  出补丁只会得到一份没人会 review 的大 diff，以上游源码仓库为准即可；
- 每次动过依赖之后，用当时的补丁核对一遍；
- 改动进入上游发布版本后，升级依赖并**删除对应补丁**。

## 历史

`cdpc` 曾在 6.1.2 上带过两份补丁（`setMaxTree` 入口、加载中断修复），
两者都已进入 **cdpc 6.1.3** 正式发布版，补丁随之删除。
